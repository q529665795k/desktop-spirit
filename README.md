# 桌面灵宠 Desktop Spirit

从一颗蛋破壳、进化成狐耳少女的安卓桌面宠物 APP。

- 目标:自用 + 抖音展示,不上架、不收费、不接广告
- 开发:Termux 写代码 → 本仓库 → GitHub Actions 自动打包 APK
- 原创开源,素材由豆包 AI 生成

## 开发步骤

1. ✅ 项目骨架(本步):空白 APP + 会呼吸浮动的蛋 + Actions 自动打包
2. ⏳ 蛋形态 + 悬浮窗(可拖动、点击气泡)
3. ⏳ 破壳 + 狐耳幼宠待机
4. ⏳ 喂食 + 摸头互动 + 饱腹度
5. ⏳ 睡觉 + 心情 + 语音吐槽(TTS)
6. ⏳ 进化完全体 + 打磨
7. ⏳ 真机测试 + 录屏发抖音

## 打包

每次 push 到 main 自动触发 Actions,APK 产物在 Actions 页面 Artifacts 下载。
